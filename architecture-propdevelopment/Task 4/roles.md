# Ролевая модель доступа

## 1. Группы пользователей

Группы повторяют структуру компании

| Группа | Кто входит |
|---|---|
| `platform-admins` | Платформенная команда |
| `devops` | DevOps-инженеры |
| `team-<домен>` | Разработчики и инженеры по эксплуатации домена |
| `security` | Специалист по ИБ. В компании он один |
| `observers` | Владельцы продуктов, бизнес-аналитики, аналитики BI |

## 2. Роли

| Роль | Права роли | Группы пользователей |
|---|---|---|
| `cluster-admin` (встроенная ClusterRole) | Полный доступ ко всем ресурсам всех namespace. Единственная роль, которая может раздавать права | `platform-admins` |
| `cluster-configurator` (ClusterRole, своя) | Настройка кластера. Секреты и правка RBAC запрещены | `devops` |
| `view` (встроенная  ClusterRole) | Просмотр ресурсов всех namespace: поды, деплойменты, сервисы, события | `observers` |
| `security-auditor` (ClusterRole, своя) | Отдельная роль ИБ. Чтение всего, что относится к безопасности. Никакой записи | `security` |
| `namespace-maintainer` (Role, своя, в namespace домена) | Работа команды в своем домене. Секреты и чужие namespace недоступны | `team-sales`, `team-utilities`, `team-finance`, `team-data`, `team-smart-home` |
